# Security Policy

## Supported versions

Only the latest release of each Redfox OSS app or library receives security fixes.

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, discussions or pull requests.**

Report them privately with GitHub's private vulnerability reporting:

1. Open the affected repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version, and steps to reproduce it.

You should get a first response within 7 days. We will keep you updated, agree a disclosure date with you, and credit you in the advisory unless you prefer to stay anonymous.
